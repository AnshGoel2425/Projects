# Projects

Smaller projects in quantum computing and machine learning, one folder each. Larger projects live in their own repositories, linked below.

## In this repository

| Project | Folder | What it is | Stack |
|---|---|---|---|
| **BB84 Quantum Key Distribution** | [`quantum/bb84-qkd`](quantum/bb84-qkd) | End-to-end simulation of BB84 with an intercept-resend eavesdropper, detected through the rise in quantum bit error rate | Qiskit, Python, Arduino |
| **Superdense Coding Simulator** | [`quantum/superdense-coding`](quantum/superdense-coding) | Sends two classical bits with one qubit, worked through for all four Bell states | Qiskit, Python |
| **Multiple Linear Regression** | [`machine-learning/linear-regression`](machine-learning/linear-regression) | Linear regression with batch gradient descent written from scratch, predicting building energy consumption | NumPy, Pandas, Seaborn |
